# Программа которая берет курс 4 валют с сайта и показывает вам





Программа позволяет увидеть курс таких валют как USD CNY GBP EUR









Чтобы пользоваться программой надо иметь python и запустить программу в cmd , idle,vs code,pycharm (что то на выбор)







Чтобы увидеть курс нужно написать валюту на выбор или exit чтобы выйти так же действия сохраняются в логи value.log
